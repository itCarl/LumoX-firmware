DMX Output

Workaround for cheap moving-head receivers that jitter when slot 1 is 0x00. Forces channel 1 to value 1 on the wire, so the start code (0x00) is never followed by another zero. Only enable when channel 1 is unused (fixtures patched ≥ 2).
